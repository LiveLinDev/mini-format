SIMA convierte una clase en un banco de preguntas para estudio adaptativo. Un modelo de lenguaje genera las preguntas en notación .mini y mini-format valida cada una contra el contrato de ítems antes de que llegue al estudiante. Los datos de esta página provienen de una clase real procesada con DeepSeek; la validación se ejecuta en este navegador con el motor de mini-format. SIMA turns a lecture into a question bank for adaptive study. A language model generates the questions in .mini notation and mini-format validates each one against the item contract before it reaches the student. The data on this page come from a real lecture processed with DeepSeek; validation runs in this browser with the mini-format engine.
