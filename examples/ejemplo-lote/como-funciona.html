02 · Una aplicación de muestra02 · A sample application

De «no puedo entrar» a una solicitud organizada.From “I can't log in” to an organized request.

Una mesa de ayuda recibe mensajes de sus clientes. La IA los resume y clasifica en fichas de soporte, también llamadas tickets. .mini comprueba esas fichas para que la aplicación pueda atender cada solicitud. Esta demo usa diez mensajes de muestra.A help desk receives customer messages. The AI summarizes and classifies them into support records, also called tickets. .mini checks those records so the application can handle each request. This demo uses ten sample messages.

  1. 1Elige si todo llega bien, un dato falla o la respuesta se corta.Choose a complete answer, an invalid value or a cut-off answer.
  2. 2Pulsa «Ver el ejemplo en acción».Press “See the example in action”.
  3. 3Mira la respuesta y las solicitudes que se pueden utilizar.See the answer and the requests your application can use.

Puedes empezar sin cuenta ni clave. «Demo sin clave» usa respuestas guardadas de una IA; mini las comprueba en tu navegador. Cambia entre .mini y JSON para comparar. Si eliges un proveedor, podrás probarlo con tu propia clave.Start without an account or key. “Demo without a key” uses saved AI answers; mini checks them in your browser. Switch between .mini and JSON to compare. You can also select a provider to try your own key.
