# `.mini-a` — Assessment items (multiple choice, Bloom + IRT 3PL + CAT metadata)

**Prefix:** `a`  **Version:** 1  **Parent:** —  **Domain:** education / adaptive assessment

One multiple-choice assessment item per line, as generated by SIMA from a lecture transcript. The selected option is the correct answer; IRT parameters feed a computerized adaptive test.

## Record layout

```
id:str | bloom:enum{L1|L2|L3|L4|L5|L6} | topic:str | statement:str | options:mlist<str>[2..6]*1 | irt:tuple(a:float,b:float,c:float) | difficulty:int[1..5] | cat:tuple(area:str,exposure_cap:float,demand:enum)
```

| # | field | type | notes |
|---|---|---|---|
| 1 | `id` | `str` | core; item identifier |
| 2 | `bloom` | `enum{L1|L2|L3|L4|L5|L6}` | core; Bloom level |
| 3 | `topic` | `str` | core |
| 4 | `statement` | `str` | core; question stem |
| 5 | `options` | `mlist<str>[2..6]*1` | core; answer options; the correct one carries * |
| 6 | `irt` | `tuple(a:float,b:float,c:float)` | core |
| 7 | `difficulty` | `int[1..5]` | core |
| 8 | `cat` | `tuple(area:str,exposure_cap:float,demand:enum)` | core |

## Header keys

| key | type | required | description |
|---|---|---|---|
| `n` | `int` | yes | number of records |
| `v` | `int` | no | contract version |
| `m` | `str` | no | psychometric model, e.g. IRT3PL |
| `d` | `str` | no | generation date YYYYMMDD |
| `l` | `str` | no | language code |
| `t` | `str` | no | topic of the bank |
| `bd` | `list` | no | Bloom distribution L1..L6 |
| `cat` | `tuple` | no |  |
| `k` | `int` | no | options per item (every options list must have exactly k elements) |
